# Airship Tycoon

Ein Tycoon-Spiel im goldenen Zeitalter der Zeppeline (1900–1930), als HTML5-Web-Game für das iPhone (hochkant).

- Luftschiffe kaufen, Routen zwischen europäischen Städten eröffnen, Ticket- und Frachtpreise festlegen
- Hangar ausbauen, Treibstoff, Wartung und Verschleiss managen, Ruf aufbauen
- Zufallsereignisse wie Stürme und Messen
- Das Spiel läuft im Hintergrund weiter (1 Echtminute = 1 Spielstunde), beim Öffnen gibt es eine Zusammenfassung

Spielen: in Safari öffnen und über „Teilen → Zum Home-Bildschirm“ als App hinzufügen.
